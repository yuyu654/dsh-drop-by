# presence-gate

**主动开口的那道门。** 一个 DSH 插件：定时看一眼主人是不是在线、刚刚在干什么、有没有话没接上，判断这一拍该不该主动说一句；该说的话再交给宿主模型写成一句话发出去。

不是定时播报器，也不是「每天早安」那种模板。它只在**有由头**的时候开口——下课了、刚回到电脑前、坐太久了、两天没说话、睡前、她发了消息而这边还没回——没有由头就一整个下午不出声。

```
每 tickMinutes 拍一次
  ├─ 读感知：进程 / 浏览器标签 / 窗口标题（可选截图+OCR） / 手机状态邮件
  ├─ 挑由头：现在符合哪一类（课上完了、刚回来、坐太久、没回、睡前……）
  ├─ 过闸门：静默时段、冷却、每日上限、同类间隔、连发退避
  ├─ 交给模型：给足上下文，让它写一句人话（可以只当草稿）
  ├─ 过 guard：长度、禁词、客服腔、不写括号动作、不许倒脏水
  └─ 发出去：拆段、隔几秒一条，像人一句一句说
```

## 它解决什么

主动说话最容易坏在两件事上：**时机**（没事找事，一天问八遍）和**内容**（模板味、查岗味、客服味）。这个插件把两件事分开治：

- **时机**交给规则：可配置的静默时段、每类由头自己的间隔、全局每日上限、被冷落之后自动拉长间隔（`feedback`）。
- **内容**交给模型 + 上下文：不是填空，而是把「她刚才说了什么、这一拍发生了什么、上一句是谁说的」一起给模型，再让它决定说不说、说什么。
- **写坏了挡得住**：`guard` 拦长度、口头禅、命令口气、客服腔、复读；拦下来的记录原因，不硬发。

## 安装

```bash
# npm
dsh plugin --profile web add presence-gate

# 或者直接从仓库
dsh plugin --profile web add github:<you>/presence-gate
```

装好后在 DSH 设置里能看到插件页；也可以纯命令行跑（见下）。

## 三条通道

| 通道 | 读 | 写 | 说明 |
|---|---|---|---|
| QQ | ✓ | ✓ | 要装 `dsh-plugin-qq-bridge` 并配对；发送走 QQ 私信 |
| 抖音 | ✓ | 可选 | 要装 `dsh-douyin-scroll`；能读私信与评论，发送默认关 |
| 主对话 | ✓ | 可选 | 宿主里的当前会话 |

没装的通道会被跳过，不会报错。

设置里的「节奏 → QQ 热聊补一句」默认关闭。打开后，同一个 QQ 私聊在三分钟内来回聊过至少两轮，普通回复发完约 15 秒后，宿主模型可以顺着原话题补一句。你发来新消息、话题已结束或没有新内容时不发。一次只补一句，之后等你重新开口并收到普通回复；不会定时追问。这一条也算每日额度，受全局静默、忙碌时段和发送开关限制；演练模式只记日志。

## 由头（topics）

课上完了、刚回到电脑前、久坐、睡前、熬夜、没回消息、压力高、明天的安排、考试临近……每一项都能单独关，也能改间隔。完整清单与默认值见 `config.example.json` 的 `content.topics`。

「没回消息」这一类可以配一个 **judge**：先把「她上一条是什么时候、说了什么」交给模型判一次——是问句、是随口一说、还是根本不用接——再决定要不要开口。避免把「嗯」当成需要回应的邀约。

## guard：写坏的话发不出去

发送前过一遍硬规则，命中任一条就丢弃或重写：

- 长度（默认 ≤60 字）与段数上限；
- 客服腔、说教腔、「希望能帮到您」这类；
- 括号里的动作描写（「(拽住衣角)」）——要撒娇就写在语气里；
- 命令口气与贬低；
- 复读：和最近发过的太像就换一句；
- 禁词：**插件不带任何具体人的口头禅**。要加自己的，写进 `local-style.json`（见下）。

## 本地私有规则：插件不带人设

插件的代码里没有「她是谁、她讨厌什么」。人格从 `dsh-agent-md` 注入的 `<DSH_HOME>/AGENT.md` 读；没有就用插件目录下自己填的 `persona.md`（首次运行自动生成一份中性模板）。

只在这台机器成立的规则——禁用的口头禅、某件旧事不能提、某个只有你们知道的称呼——放进 **`local-style.json`**，格式见 `local-style.example.json`：

```json
{
  "taboos": [{ "code": "CATCHPHRASE", "pattern": "别多想", "why": "说滥了" }],
  "notes": ["胃不好的是我，不是她——别倒过来查她"],
  "samples": ["跑完了。第三行那个报错是路径写错，改了。"]
}
```

这个文件不进 npm 包、不进 git。删掉它，插件就退回通用形态。

## 配置

首次运行会在插件目录生成 `config.json`（`config.example.json` 是带说明的样例）。几个最常改的：

| 键 | 默认 | 说明 |
|---|---|---|
| `tickMinutes` | 10 | 多久判一次 |
| `quietHours` | `[["22:30","07:30"]]` | 全局静默，可多段 |
| `rules.dailyCap` | 6 | 一天最多主动说几次 |
| `rules.minGapMin` | 60 | 两次开口的最小间隔 |
| `rules.replyCooldownMin` | 1 | 她刚说完话后的冷却 |
| `channels.*.peerId` | 空 | 收件人；空着就发不出去 |
| `content.maxChars` | 60 | 一句话的上限 |
| `content.llm.profile` | `headless` | 用哪个 DSH profile 生成内容 |
| `persona.localFile` | `persona.md` | 没有 AGENT.md 时用它 |

`content.forward`（看视频）与 `perception.l3`（截图 + OCR）默认可以不开：前者需要本机一个下载/转写的脚本，后者只在判定为「该说」时才触发。

## 命令行

```bash
node src/run.js --status     # 现在是什么状态，上一拍判了什么
node src/run.js --once       # 立刻判一拍（dryRun 时不发送）
node src/run.js --compose    # 只看看会说什么（不通模型）
node src/run.js --why        # 上一拍为什么是这个结论
node src/run.js --windows    # 各功能的执行时段
npm test                     # 623 个用例
```

日志在 `logs/`：每拍一行 JSONL。

## 边界

- **不发未经确认的话**：`send.requireConfirm` 默认开，主动消息先落草稿。
- **不窥探内容**：截图默认关；开了也不落盘，日志只记命中关键词。
- **不做平台操作**：不点赞、不关注、不加好友，只用各通道的「读私信 / 发私信」。
- **可整体关掉**：`enabled: false` 或 `dryRun: true`。
