# dsh-drop-by

DSH 设置页显示为「陪伴」。本机从旧版升级时可沿用原安装目录，保留配置、人格和探索进展。

**主动开口的那道门。** 一个 DSH 插件：定时看一眼主人是不是在线、刚刚在干什么、有没有话没接上，判断这一拍该不该主动说一句；该说的话再交给宿主模型写成一句话发出去。

不是定时播报器，也不是「每天早安」那种模板。它只在**有由头**的时候开口——下课了、刚回到电脑前、坐太久了、两天没说话、睡前、她发了消息而这边还没回——没有由头就一整个下午不出声。

```
每 tickMinutes 拍一次
  ├─ 读感知：进程 / 浏览器标签 / 窗口标题（可选截图+OCR） / 手机状态邮件
  ├─ 挑由头：现在符合哪一类（课上完了、刚回来、坐太久、没回、睡前……）
  ├─ 过闸门：静默时段、冷却、每日上限、同类间隔、连发退避
  ├─ 交给模型：给足上下文，让它写一句人话（可以只当草稿）
  ├─ 过 guard：长度、禁词、客服腔、不写括号动作、不许倒脏水
  └─ 发出去：拆段、隔几秒一条，像人一句一句说
```

### 法定节假日

忙碌时段是按星期循环的（她周几几点在上课），法定节假日那天按国务院的放假通知整天空出来：忙碌时段不生效，静默照旧。2026 年全年已经内置在 `src/holidays.js`（元旦、春节、清明、劳动节、端午、中秋、国庆，含调休上班的周末），新一年发通知后加一项即可；表里没有的日期可以在设置「日常 → 额外放假的日子／调休上班的周末」手动补，调休上班日优先，那天忙碌时段照常生效。

不想改源码也行：在「日常 → 节假日日历接口」填一个返回 JSON 的地址（`{year}` 会替换成四位年份，如 `https://example.com/holiday/{year}.json`），然后让模型调 `presence_holiday_calendar`（action=refresh）拉一次，结果写进 `data/holidays-<年>.json`，之后判断只读缓存、不联网。接口只要给出 `{year, off: [...], work: [...]}`，或者第三方的 `{holiday: {"01-01": {holiday: true|false, name, date}}}` 形状都能认；自动补班的周末按名字里的「调休/补班」识别。跨年时如果内置表还没覆盖今年、接口也配了，插件启动会自己补一次；失败只记日志，不影响正常拍。

## 它解决什么

主动说话最容易坏在两件事上：**时机**（没事找事，一天问八遍）和**内容**（模板味、查岗味、客服味）。这个插件把两件事分开治：

- **时机**交给规则：可配置的静默时段、每类由头自己的间隔、全局每日上限、被冷落之后自动拉长间隔（`feedback`）。
- **内容**交给模型 + 上下文：不是填空，而是把「她刚才说了什么、这一拍发生了什么、上一句是谁说的」一起给模型，再让它决定说不说、说什么。
- **写坏了挡得住**：`guard` 拦长度、口头禅、命令口气、客服腔、复读；拦下来的记录原因，不硬发。

## 安装

```bash
# npm
dsh plugin --profile web add dsh-drop-by

# 或者直接从仓库
dsh plugin --profile web add github:<you>/dsh-drop-by
```

装好后在 DSH 设置里能看到插件页；也可以纯命令行跑（见下）。

## 三条通道

| 通道 | 读 | 写 | 说明 |
|---|---|---|---|
| QQ | ✓ | ✓ | 要装 `dsh-plugin-qq-bridge` 并配对；发送走 QQ 私信 |
| 抖音 | ✓ | 由抖音插件负责 | 要装 `dsh-douyin-scroll` 并开启聊天盯梢 |
| 主对话 | ✓ | — | 作为宿主活动信号 |

没装的通道会被跳过，不会报错。

设置里的「节奏 → QQ 热聊补一句」默认关闭。打开后，同一个 QQ 私聊在三分钟内来回聊过至少两轮，普通回复发完约 15 秒后，宿主模型可以顺着原话题补一句。只依据最近的 QQ 对话补话。你发来新消息、话题已结束、正在等对方行动，或草稿偏离原话题时不发。一次只补一句，之后等你重新开口并收到普通回复；不会定时追问。这一条也算每日额度，受全局静默、忙碌时段和发送开关限制；演练模式只记日志。

## 由头（topics）

「高级 → 问一次最近在忙的项目」默认关闭。开启后，插件在普通主动消息的时段和额度允许时，可以由宿主模型按当前人设向已有 QQ 对话的收件人问一次。写不出自然的问句就跳过；真实发出才记为问过，不催答。同一私聊里一天内读到相关回复才记为近期背景，不能用它推断对方卡住。

### 自主探索

设置 → 日常 → 自动自主探索，默认关闭。可以在设置页点「试跑一轮」，也可以在 DSH 对话里要求「用 dsh-drop-by 试跑一轮自主探索」。研究和休闲进展分别保存。「高级 → 每几轮安排一次休闲」默认为 3，填 1 每轮休闲，填 0 关闭休闲轮；搜索不可用时也按这个节奏选方向。

- **近一轮探索主题**：可在「自主探索」卡片顶部或「日常 → 近一轮探索主题」临时指定下一轮优先围绕的题目；成功跑完一轮非跳过结果后会自动清空，下一轮恢复自由选题。长期想追的作品、公开网站或待确认的本地事实，可写在「最近对什么好奇」。
- **只在谷时自动探索**：在「日常 → 探索间隔」下方打开后，自动探索仅在 DeepSeek API 官方低谷时段（5 折空闲时段，按北京时间并结合日历接口判定：工作日排除法定节假日的 09:00–12:00、14:00–18:00 为高峰跳过；其余时段、周中法定节假日全天以及周末含调休上班周末全天均为谷时）执行；手动点「试跑一轮（不发送）」不受限制。

检测到网页要求登录时，面板显示站点链接。启用主动分享时，登录提醒可经现有 QQ 发送规则按站点提醒一次。请在网站的登录页完成登录。网页搜索目前走公开的 `web_fetch`，不接管用户的浏览器会话；登录后的漫画正文还需要能复用登录态的阅读入口和支持图片的模型。

在「高级」开启网页或视频探索后，网页搜索优先使用 `dsh-free-search` 的 `advanced_search`，再回退到 DSH 的 `web_search`，用 `web_fetch` 读最多两页。视频每轮最多一条，画面需要 `dsh-video-storyboard` 和支持图片的模型，抖音还需要取流配置。只有字幕、口播、标题或摘要时，结果会标出依据。没有搜索工具时可继续做文字推演。启用「让探索进展参与主动分享」后，喜欢的内容可作为分享候选，带原链接走现有发送规则。

市场包不包含本机旧探索 driver、固定题目、代理管理或余额/轮次汇报。宿主模型不可用时，旧版普通消息 CLI 备用入口需要显式配置 `DSH_ELECTRON` 与 `DSH_CLI`（或对应设置）。

「高级 → 探索心情」默认关闭。开启后，探索可在同一次模型调用里记一句有缘由的感受，两小时后不再使用。支持 `dsh-drop-by/qq-reply` 的 QQ 桥会给配置收件人的普通私聊提供近三天探索进展和有效心情。回复仍优先接住当前消息。

心情只做语气，不做素材——注入前先把业务词剥掉（术语、参数、标题、推导都不进 prompt），只留「有点闷」「挺顺」这种状态；私聊背景里的「当前感受」同样只留情绪。正在说的那一句来自记忆种子时，这一拍不再叠探索心情，也不塞「最近聊到的」，一拍只给一个锚点。写出来的话若直接抄了心情原话，guard 会以 `MOOD_LEAK` 打回。种子里的专有名词（书名、引号里的名字、`local-style.json` 的 `names`）会单独标出来，要求照抄，不许改写或另编。

「数据从哪来 → 延续 QQ 聊天的心情（情绪插件）」与自主探索结果均已接入 `emotion-state-portrait` 插件：插件启动时或点击设置页「一键修复本机配置」，会自动把情绪插件的残余作者路径、密钥与本机运行目录对齐为当前环境，无需手工改配置文件。

长期记忆兼容 `dsh-fish-memory` 的工作区模式（`ws_*.json`）与会话模式（`session-*.json`），设置页可独立选择发消息时的读取范围，也可展开「挑选会话并入…」预览并勾选历史会话并入指定工作区（写前自动生成 `.bak-before-merge` 备份，支持一键撤销）。

课上完了、刚回到电脑前、久坐、睡前、熬夜、没回消息、压力高、明天的安排、考试临近……每一项都能单独关，也能改间隔。完整清单与默认值见 `config.example.json` 的 `content.topics`。

「没回消息」这一类可以配一个 **judge**：先把「她上一条是什么时候、说了什么」交给模型判一次——是问句、是随口一说、还是根本不用接——再决定要不要开口。避免把「嗯」当成需要回应的邀约。

### 外部聊天的上下文续接

「高级」里默认在绑定会话完成一轮、上下文占用达到 80% 时，在同一工作区预建下一条会话，并发一条 QQ 提醒。默认预备磁盘绑定，当前旧会话继续收发，重启 DSH 后切换。也可以在 QQ 桥面板停用旧绑定，再绑定新会话。面板如果保留两条启用的绑定，QQ 桥会同时投递。

切换后的首条消息会带上旧会话当时最近十条用户或助手消息。旧会话暂时读不到时用预备快照。前情只加在首条消息里，不单独请求模型。消息条数可在设置里改，填 0 只建新会话。建议在 dsh-fish-memory 开启按工作区共用记忆。

### QQ 连发合并

配置的 QQ 私聊在短时间内连发消息时，陪伴等最后一条发完后合成同一轮交给 DSH，文本和已交给宿主的附件一起投递。「时间间隔 → QQ 连发消息合并等待」默认 3500 毫秒，最少 3000 毫秒。原版 QQ 桥支持把一个联系人绑定到多个会话，这种绑定仍各自投递。

### QQ 确认后换来源

开启探索网页、主动分享和真实发送。当研究只找到标题、摘要或登录页，陪伴可在配置的 QQ 私聊发出「要不要我换个源去找正文？」。这条消息仍需满足主动分享的间隔、时段和额度。发出的消息带有换源标记时才登记凭证。送达后默认 15 分钟内，模型结合提议识别同意或拒绝。「可以，去知乎或者 CSDN 看看」会把指定站点带进搜索。拒绝、换话题或过期会清掉凭证。

原版 QQ 桥会为这条回复生成一句简短的接单消息。陪伴在后台按上一轮关键词换源，随后用自己的 QQ 发送通道报告「找到正文」「没拿到正文」或执行失败。若搜索先结束，默认最多等接单回复 30 秒。这两个时间可在「时间间隔」调整。

使用 QQ 桥已有的上下文接口。可发送的 OneBot HTTP API 和发送令牌用于回传结果，HTTP 上报令牌不再是功能开关。QQ 桥的 HTTP 上报入口如果没设令牌且可被其他人访问，上报里的 QQ 号可能被伪造；如果使用 HTTP 上报，应在桥端保护该入口。

### QQ 主动指令

开启「接收 QQ 主动任务指令」、真实发送，并配置上一节的结果回传接口后，可以对陪伴说「有空能帮我看看反时限过流保护的公开实现吗」「昨天的探索笔记能不能整理下」「再探索一次插排」或「帮我跑个测试」。意图判断使用当前 DSH 模型，仅把这条消息和有效的待确认提议传给分类器。识别超时时间默认 5 秒，可在「时间间隔」调整。

分类只允许公开搜索、推进研究、整理陪伴的探索笔记和运行陪伴自带的快速测试。普通 QQ 回复负责接单，后台完成后直接用陪伴的 QQ 发送通道回传结果。回传受发送开关约束，用户主动任务不受日常静默、间隔和配额限制。

## guard：写坏的话发不出去

发送前过一遍硬规则，命中任一条就丢弃或重写：

- 长度（默认 ≤60 字）与段数上限；
- 客服腔、说教腔、「希望能帮到您」这类；
- 括号里的动作描写（「(拽住衣角)」）——要撒娇就写在语气里；
- 命令口气与贬低；
- 复读：和最近发过的太像就换一句；
- 禁词：**插件不带任何具体人的口头禅**。要加自己的，写进 `local-style.json`（见下）。

## 本地私有规则：插件不带人设

插件的代码里没有「她是谁、她讨厌什么」。人格从 `dsh-agent-md` 注入的 `<DSH_HOME>/AGENT.md` 读；没有就用插件目录下自己填的 `persona.md`（首次运行自动生成一份中性模板）。

只在这台机器成立的规则——禁用的口头禅、某件旧事不能提、某个只有你们知道的称呼——放进 **`local-style.json`**，格式见 `local-style.example.json`：

```json
{
  "names": ["逸遐", "艾栩"],
  "taboos": [{ "code": "CATCHPHRASE", "pattern": "别多想", "why": "说滥了" }],
  "notes": ["胃不好的是我，不是她——别倒过来查她"],
  "samples": ["跑完了。第三行那个报错是路径写错，改了。"]
}
```

这个文件不进 npm 包、不进 git。删掉它，插件就退回通用形态。

## 配置

首次运行会在插件目录生成 `config.json`（`config.example.json` 是带说明的样例）。几个最常改的：

| 键 | 默认 | 说明 |
|---|---|---|
| `tickMinutes` | 10 | 多久判一次 |
| `quietHours` | `[["22:30","07:30"]]` | 全局静默，可多段 |
| `rules.dailyCap` | 6 | 一天最多主动说几次 |
| `rules.minGapMin` | 60 | 两次开口的最小间隔 |
| `rules.replyCooldownMin` | 1 | 她刚说完话后的冷却 |
| `channels.*.peerId` | 空 | 收件人；空着就发不出去 |
| `content.maxChars` | 60 | 一句话的上限 |
| `content.llm.profile` | `headless` | 用哪个 DSH profile 生成内容 |
| `persona.localFile` | `persona.md` | 没有 AGENT.md 时用它 |

`content.forward`（看视频）与 `perception.l3`（截图 + OCR）默认可以不开：前者需要本机一个下载/转写的脚本，后者只在判定为「该说」时才触发。

## 命令行

```bash
node src/run.js --status     # 现在是什么状态，上一拍判了什么
node src/run.js --once       # 立刻判一拍（dryRun 时不发送）
node src/run.js --compose    # 只看看会说什么（不通模型）
node src/run.js --why        # 上一拍为什么是这个结论
node src/run.js --windows    # 各功能的执行时段
npm test                     # 623 个用例
```

日志在 `logs/`：每拍一行 JSONL。

## 边界

- **不发未经确认的话**：`send.requireConfirm` 默认开，主动消息先落草稿。
- **不窥探内容**：截图默认关；开了也不落盘，日志只记命中关键词。
- **不做平台操作**：不点赞、不关注、不加好友，只用各通道的「读私信 / 发私信」。
- **可整体关掉**：`enabled: false` 或 `dryRun: true`。
