# 陪伴 · dsh-drop-by

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://github.com/yuyu654/dsh-drop-by/blob/main/LICENSE)

**让你的 DS 主动来找你，也有自己的新鲜事想分享。**

一个为 DeepSeek Harness（DSH）打造的主动陪伴插件。新装默认走 **DSH 内部会话**，无需额外桥接即可开箱体验；也可以随时无缝切换到 **QQ** 或 **抖音私信**，**三个通道共用同一条 DSH 会话**。

TA 会沿用你设定的人设、拥有自己的作息与自主探索兴趣，在合适的时机主动聊两句，也懂得在你忙碌、全屏游戏或想结束话题时安静收尾。

[快速开始](#quick-start) · [三通道共用会话](#chat-channels) · [自主探索](#exploration) · [角色作息与节奏](#persona-memory) · [扩展接入](./docs/EXTENSIONS.md) · [鱼鱼状态](./docs/fish-condition.md) · [更新日志](./CHANGELOG.md) · [常见问题](#faq) · [Releases](https://github.com/yuyu654/dsh-drop-by/releases)

> 早期测试版本：内部会话可零前置开箱使用；QQ（本机验证组合 `dsh-plugin-qq-bridge` + `snowluma`）、抖音私信、网页/视频探索、记忆、情绪和手机感知均可按需开启。

## 核心体验

- **开箱即用，桌面与手机共用同一条会话**：新装默认使用 DSH 内部会话，三通道均可在设置页直接选择或新建会话；切到 QQ 或抖音私信时自动沿用同一条会话，并支持按真实上下文百分比预建长会话接力。
- **会主动开口，更懂得什么时候闭嘴**：拥有独立的角色作息（每日浮动、睡前轻声与睡前/醒后招呼），内置零 Token「看眼色」小算盘与 Windows 全屏游戏避让；自动识别“去忙了 / 晚安 / 连续短回复”等收尾信号进入冷静期，也可按需开启「被敷衍 / 无理由不回会闷闷与生气」情绪状态机。
- **有自己正在琢磨的事**：支持深度推进（带内置遗忘/召回记忆）与轻量化探索两档模式，支持轻量看图与 Edge 多步网页浏览（看漫画、读小说、最小化运行），可独立指定探索模型，用多种自然开场方式分享发现。
- **记得约定、能派活，也能省 Token**：内置轻量「约定小本本」（支持私聊查询/取消与防误删），手机端可直接派搜索/探索任务并随时一键中止；提供配置预设、精简陪聊工具（隐藏低频工具省 Token）、Flash 模型免思考加速、连通测试、安全试跑与 7 日克制日报。

<a id="quick-start"></a>

## 3 分钟快速开始（最小路径）

### 1. 安装插件

在 DSH 插件市场搜索 `dsh-drop-by`，或使用 DSH CLI 安装到你实际使用的 profile（桌面端通常为 `desktop`，网页端为 `web`）：

```bash
dsh plugin --profile desktop add @joshin/dsh-drop-by
```

也可通过 GitHub 地址安装：`https://github.com/yuyu654/dsh-drop-by`。安装后重启 DSH，在设置中打开「陪伴」。

### 2. 绑定一个内部会话（无需先装 QQ / 抖音插件）

全新安装默认主通道为 **内部会话（DSH 桌面端）**（已有旧配置升级保持原主通道不变）：

1. 在「主聊天接口与通道开关」卡片中，从下拉列表选择一个已有 DSH 会话点击「绑定所选」，或直接点击「新建陪伴会话」。
2. 若已使用 `dsh-agent-md`，陪伴会自动读取全局人格；也可在插件目录填写 `persona.md`。

### 3. 自检并安全试跑，再开启实际发送

1. 展开设置页顶部的 **「快速引导与自检」**，先跑一次「检查连通状态」，再点 **「试跑一次」**（安全试跑不真发消息、不改运行状态和配额，可直接查看命中原因与草稿口吻）。
2. 默认开启「演练模式」、关闭「允许真的发送」。确认效果符合预期后，关闭「演练模式」并打开「允许真的发送」即可开始日常陪伴。

### 隐私与费用边界

- **默认安全静默**：初始开启演练模式且关闭真实发送；命中全局静默、忙碌时段、角色睡眠、全屏游戏或收尾冷静期时不会硬发消息。
- **按需接入**：自主探索、网页搜索、视频看图、长期记忆、情绪画像、桌面感知和手机健康数据均为独立开关，默认关闭高耗或外部依赖项。
- **本地存储与外发说明**：配置、状态与日志保存在本机并由 `.gitignore` 排除；开启模型判断、探索或外部聊天入口时，必要上下文会按你的配置提交给对应模型或服务，详情见 [数据流向与本地文件](#data)。

<a id="chat-channels"></a>

## 三通道共用会话：内部会话 / QQ / 抖音私信

陪伴始终只启用**唯一主聊天通道**（三选一），避免多端重复回复。三个通道共用同一条 DSH 会话（`sessionId`），无论最初用哪个通道绑定或自动新建了会话，后续切换都会直接沿用。

| 项目 | 内部会话（DSH 桌面端，新装默认） | QQ | 抖音私信 |
|---|---|---|---|
| 前置插件 | 无（零依赖开箱即用） | `dsh-plugin-qq-bridge` | `dsh-douyin-scroll` |
| 首次建会话 | 设置页手动选择或一键新建 | 设置页选/建会话，或配对后自动新建/沿用 | 设置页选/建会话，或自动新建/沿用 |
| 消息接收 | 监听 DSH 宿主会话事件，实时 | QQ 桥实时接入 | 陪伴定时轮询（默认 30 秒，10–300 秒可调） |
| 离开电脑 | 需在 DSH 客户端查看 | 手机随时收发与派任务 | 手机随时收发与派任务 |
| 主动消息排版 | 直接投递到已绑定 DSH 会话 | 支持按句分段发送 | 通常合并发送，减少等待 |
| 切换影响 | 停用旧 QQ 绑定，无需重启 | 恢复或自动绑定到共用会话 | 关闭原抖音聊天盯梢，必要时提示重启 |

<details>
<summary>展开查看：QQ、抖音私信配置步骤与长会话接力说明</summary>

### 切到 QQ

1. 安装并启用 `dsh-plugin-qq-bridge`，完成登录与配对。
2. 在「主聊天接口与通道开关」填写目标联系人 QQ 号，将主通道切换为「QQ」。
3. 若已有内部会话或抖音共用会话，陪伴会自动将 QQ 绑定到该会话；若此前尚未建立会话，陪伴会沿用唯一权威私聊绑定或自动新建一条共用会话并绑定。

> 从 QQ 切走时，若同一联系人有多条启用的私聊绑定，请先在 QQ 桥面板保留唯一权威绑定。

### 切到抖音私信

1. 安装 `dsh-douyin-scroll` 并完成登录，与目标联系人建立私信会话。
2. 在陪伴设置页将主通道切换为「抖音私信」。联系人 `sec_uid` 和昵称可自动从抖音插件读取，也可手动填写。
3. 切换时陪伴会自动关闭原抖音「聊天盯梢」，并沿用已有的共用会话（或新建一条）。使用陪伴接管期间请保持原聊天盯梢关闭，避免重复回复。
4. 抖音 IM 接口会检测请求模式，密集轮询可能触发 `too many requests` 限流，轮询间隔最低为 **10 秒**，失败时自动退避。

### 手机端私聊派任务与中止

在 QQ、抖音私信或内部会话中可以直接说（实际接单口吻由人设生成）：

- “帮我查一下反时限过流保护的开源实现。”
- “继续推进刚才那个探索。”
- “整理一下昨天的探索笔记。”
- 在 TA 提出换源请求后回复：“可以，去知乎找找看。”
- 需要中断时可在私聊发 **「中止后台任务」** 或 **「中止自主探索」**（两者独立，互不干扰），也可直接点设置页顶栏的中止按钮。

支持的任务会在后台执行，完成后经当前主通道直接回传结果，不等待日常主动消息额度。

### 长会话接力

默认在绑定会话完成一轮后按 DSH 界面显示的真实上下文占用率检查，达到 **80%**（可调 10%–95%）时自动在同工作区预建续聊新会话，并通过当前主通道提醒（内部会话 / QQ / 抖音均支持）。切换后新会话收到第一条消息时只搬运最近 **10 条**（可调 0–50 条）真实聊天记录，不重复搬入系统提示词。建议搭配 `dsh-fish-memory` 工作区共用记忆保留更长期背景。

<a id="exploration"></a>

## 自主探索：深度研究与轻量化闲逛

在「自主探索」卡片中可先点「试跑一轮（不发送）」体验效果，再按需开启「自动自主探索」「探索时搜索网页」「探索时找视频」与「让探索进展参与主动分享」。

| 设置 | 作用 |
|---|---|
| 探索方式 | **深度推进**（保留研究线、进度与内置遗忘/召回记忆）或 **轻量化探索**（单次浅看一件小事、不建长线任务、省 Token） |
| 探索倾向 | **偏休闲 / 均衡（默认）/ 偏研究**，深度推进和轻量化模式均适用 |
| 网页与看图方式 | **轻量看图**（抓图/单帧识图，省开销）或 **调网站浏览**（无头 Edge 多步点击、目录筛选、看漫画画布、读小说正文，支持最小化运行，默认上限 40 步可调） |
| 独立探索模型 | 可单独指定当前账号下任意 API 模型，默认跟随绑定会话 |
| 最近对什么好奇 | 写长期关注的主题、作品或网站（支持多主题/多作品拆分轮选与常见漫画/小说平台来源映射）；留空则按人设自主选题 |
| 近一轮探索主题 | 临时指定下一轮具体题目，成功跑完一轮后自动清空 |
| 轻反馈与好奇候选 | 进展旁可点「想多听听 / 换个方向 / 先放着」（再点可取消）；聊热的探索分享与私聊转发会自动沉淀为近期好奇候选 |
| 只在谷时自动探索 | 按北京时间与日历避开工作日高峰（手动试跑不受限） |

- **网页与视频证据边界**：网页优先用 `dsh-free-search`（自动回退宿主搜索）+ 公开正文/浏览器抓取（不继承个人登录态）；视频每轮最多 1 条，画面理解需 `dsh-video-storyboard` + 支持图片的模型。分享时严格按实际证据区分“查到 / 看过 / 猜想”，同一作品仅首次分享附链接（后续推进不刷屏），并使用多种轮换开场方式（你猜、站队、自曝、卖关子、生活衔接等），避免模板腔。
- **自动探索节奏**：默认关闭，开启后默认间隔 **180 分钟**；静默、忙碌、全屏游戏与角色睡眠时段自动暂停。

<a id="persona-memory"></a>

## 角色作息、对话节奏与记忆心情

### 角色作息与早晚招呼

在「角色作息」组设置 TA 的入睡与醒来基准（默认 **22:00–06:30**，每日 ±30 分钟确定性浮动），设置页会直接展示今日实际睡醒时间：

- **睡前与睡眠中**：临睡前 30 分钟主动口吻更轻短；入睡后暂停主动开口与自动探索；若你在她睡着时发消息，仍照常回复，口吻可带一点被叫醒的困意。
- **作息由头**：实际入睡前 10 分钟与醒来后 10 分钟可顺口道一声晚安/早安（不计入接住率惩罚；若 120 分钟内刚互道过早晚安则自动跳过不重复）。

### 对话节奏、防打扰与情绪状态

- **开场好接、续聊克制**：主动开场给对方留好接的话头；进入对话后跟着用户节奏走，不每句追问。
- **收尾信号冷静期**：检测到“去忙了 / 晚安 / 先这样”或连续简短敷衍回复时，回复顺势收尾，并触发主动冷静期（默认 **120 分钟**，可调），这段时间不再主动打扰（用户先开口照常回）。对「等我 / 出来吧」等约定的简短确认（「嗯嗯 / 好的 / 收到」）不会误判为敷衍收尾。
- **本地「看眼色」小算盘**：零 Token 本地打分，结合时段、话题、口头说明“在忙/上课/开会到几点”与桌面活跃度，默认只记分观察，切到低分拦截模式可在不合适时机直接跳过模型判断省 Token。
- **Windows 全屏游戏避让**：通过 Windows 原生 API 检测全屏应用与常见反作弊进程，游戏及退出后的缓冲期内自动避让；停用插件时自动释放辅助进程并清理临时缓存。
- **被敷衍 / 无理由不回会闷闷与生气（可选，默认关闭）**：3 次递进（闷闷不追问 → 更失落 → 生气慢回且暂停主动分享、首次按人设说明原因；补说在忙/上课理由或道歉当轮立刻消气，或满衰减窗口自然恢复）。主动消息超过可配时长（默认 90 分钟）无理由不回同样计入，随口话敷衍不计但不回计入；同一段聊天（30 分钟内）认真回过一次不计入并抵消之前攒的闷闷次数；答应约定与静默/忙碌免责，并支持轻量模型判别防否定句误消气。
- **热聊补一句（可选）**：开启后仅在用户回复有实际内容与互动深度时才会自然补话，热度一降自动停手。

### 约定小本本、日报与接住率

- **约定小本本**：在「高级」中开启。只在私聊出现时间线索时抽取，不逐轮分析闲聊；明确短时提醒到点优先走轻量模型按人设生成，普通未来事项在日常间隔允许时跟进；支持设置页划掉与私聊直接查看/按名称或最近一条取消（拦截否定句、假设句并防清空后旧抽取写回）。
- **近期日报与接住率**：最多回顾 7 个记录日，总结忙碌、静默、角色休息与间隔保护带来的克制记录；分由头接住率可展开逐条明细，支持手动补标或撤销。

### 人格、记忆、心情与扩展

- **人格**：优先读取 `dsh-agent-md` 全局人格（可选叠加项目人格），否则读取本目录 `persona.md` 或内置简短口吻；禁忌词与个人习惯可配在 `local-style.json`（格式见 [local-style.example.json](https://github.com/yuyu654/dsh-drop-by/blob/main/local-style.example.json)）。
- **长期记忆与第三方扩展**：支持 `dsh-fish-memory` 等记忆源（提供“预览 → 备份 → 合并旧会话记忆到工作区 / 一键撤销”），深度探索自带内置记忆；设置页支持全局搜索、一键配置预设，并统一展示记忆、心情（防冲突）和只读探索工具三类扩展接入（详见 [docs/EXTENSIONS.md](./docs/EXTENSIONS.md)）。
- **心情**：支持「探索心情」与 `emotion-state-portrait` 情绪画像；心情只影响说话口吻，不会凭空催回复。

## 配套安卓应用：鱼鱼状态（可选）

「鱼鱼状态」（FishCondition）可采集华为运动健康中的睡眠、步数、压力与系统手机使用时间，经邮箱摘要同步给电脑端陪伴插件，让 TA 在熬夜、睡少、久坐或步数异常时自然关心一句。

完整下载链接、权限设置、邮箱收发配置与排障说明见单独文档：**[配套安卓应用：鱼鱼状态使用指南](./docs/fish-condition.md)**。

## 常用设置与默认值

以下为全新安装的默认值；已有配置升级以设置页当前显示为准。

| 设置 | 默认值 | 说明 |
|---|---|---|
| 主聊天接口 | 内部会话（DSH 桌面端） | 内部会话 / QQ / 抖音私信三选一，共用同一会话（旧配置升级保持原通道） |
| 配置预设 | 自定义 | 设置页顶栏可一键切换预设，并自动保留自定义快照 |
| 演练模式 / 允许真的发送 | 开启 / 关闭 | 双重安全闸，确认效果后再开启真实发送 |
| 每拍间隔 | 10 分钟 | 检查是否有适合开口的由头，不等于每 10 分钟发一条 |
| 每日主动上限 / 最短间隔 | 3 条 / 240 分钟 | 可开启分档间隔与冷落退避 |
| 全局静默 | 22:30–07:30 | 限制主动判断、自动探索与邮箱收取 |
| 角色作息 | 22:00–06:30（±30 分钟） | 含临睡轻声、睡眠暂停、睡前/醒后 10 分钟作息招呼 |
| 对方收尾后暂停主动 | 120 分钟 | 识别收尾信号后留出安静空间，填 0 关闭 |
| 本地看眼色小算盘 | 只记分观察 | 零 Token 本地打分；切到低分拦截可直接跳过不合适拍子省 Token |
| 被敷衍或不回会闷闷与生气 | 关闭 | 3 次递进（不回默认 90 分钟、衰减 6 小时、生气慢回 25–50 秒均可配） |
| Windows 全屏游戏避让 | 开启 | 识别全屏应用与反作弊进程自动避让（含退出全屏缓冲期） |
| 自主探索 | 关闭（深度推进 / 均衡 / 180 分钟） | 支持轻量看图与 Edge 多步浏览，可独立选模型或切轻量化省 Token |
| 约定小本本 | 关闭 | 在「高级」中开启，仅抽取带时间线索的约定，支持私聊查看与防误删取消 |
| 连发消息合并 / 热聊补一句 | 3500 毫秒 / 关闭 | 补话受回复最少字数（默认 6 字）与热度限制 |
| 长会话接力 | 开启（80% 阈值，带 10 条） | 按真实上下文占比预建新会话并提醒，仅搬运真实聊天记录 |
| 精简陪聊工具 | 关闭 | 在「高级」打开，只从绑定会话隐藏低频开发、分镜和搜索辅助工具减少新会话上下文占用。其他会话和陪伴后台照常使用。需要宿主支持按会话筛选工具 |

### 兼容性与边界

- **需要 DSH 保持运行**：电脑关机、休眠或 DSH 退出后，后台陪伴停止。
- **桌面感知主要适配 Windows**：键鼠空闲、前台窗口、全屏避让与系统 OCR 依赖 Windows 能力，浏览器标签读取需 Edge 调试端口；非 Windows 环境可正常使用聊天、作息、约定与探索能力。
- **网页与视频边界**：后台网页探索仅读公开资料，不继承个人登录态；视频看图需模型本身支持图片输入。
- **私聊任务边界**：支持公开资料搜索、推进探索、整理笔记与插件自检，不是任意本地代码执行入口。

## 常见问题

<details>
<summary>装好了，为什么一直不主动说话？</summary>

打开设置页顶部的「快速引导与自检」，依次点「检查连通状态」与「试跑一次」即可看到具体原因。最常见原因：还没绑定内部会话、仍处于「演练模式」或「允许真的发送」未开、命中静默/忙碌/全屏游戏/角色睡眠/收尾冷静期，或当前确实没有合适由头。

</details>

<details>
<summary>我离开电脑了，还能在手机上聊吗？</summary>

可以。默认关闭「只在电脑前才主动开口」，只要运行 DSH 的电脑保持开机与宿主运行，切到 QQ 或抖音主通道后即可在手机随时接收主动消息与派任务。

</details>

<details>
<summary>从内部会话切到 QQ 或抖音，以前的对话会断掉吗？</summary>

不会。三个通道共用同一条 DSH 会话，切换时会自动沿用当前 `sessionId`（首次切 QQ 或抖音无会话时自动新建）。若再搭配 `dsh-fish-memory` 工作区记忆，长会话接力也能延续更久的背景。

</details>

<details>
<summary>为什么探索结束了，没有马上发给我？</summary>

探索进展会先保存。开启「让探索进展参与主动分享」后，它才作为主动消息候选参与常规时段、间隔与冷静期判断；你主动派发的私聊任务才会走完成后立即回传流程。

</details>

<details>
<summary>静默或关闭陪伴后，QQ 为什么还能回复？</summary>

陪伴的主动逻辑与 QQ 桥普通私聊回复是不同入口。若要彻底停止 QQ 自动回复，请同时在 QQ 桥停用对应绑定（切回「内部会话」或「抖音私信」时陪伴会自动停用对应 QQ 绑定）。

</details>

## 数据流向与命令行排障

<details>
<summary>展开查看：本地文件清单、隐私边界与 CLI 排障命令</summary>

### 数据流向与本地文件

- 启用相关能力后，聊天、记忆、探索进展与状态摘要会按配置交由你在 DSH 中选择的模型服务处理；网页搜索与邮箱读取会连接对应外部服务。
- 以下个人配置与运行目录已由 `.gitignore` 排除，提交 Issue 前请先脱敏：

```text
config.json             本机设置
credentials.json        邮箱凭据
state.json              运行状态
persona.md              本机人格
local-style.json        本机表达规则
data/                   探索、约定、内部会话记录与会话交接数据
logs/                   运行日志与归档日报
```

### 命令行与排障

在插件目录运行（Node.js 需满足 [package.json](./package.json) 要求）：

```bash
node src/run.js --status     # 查看当前状态
node src/run.js --once       # 执行一拍；是否真发由当前配置决定
node src/run.js --why        # 查看命中或跳过原因
node src/run.js --windows    # 查看配置的运行时段
node src/run.js --persona    # 检查人格来源与内容
node src/run.js --compose    # 查看内容生成结果
node src/run.js --mail       # 查看邮箱状态与已缓存摘要
node src/run.js --mail-now   # 手动强制收取一次邮件
npm test                     # 运行插件测试
```

完整配置参考 [config.example.json](./config.example.json)。

</details>
