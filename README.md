# dsh-drop-by

**主动开口的那道门。** 一个用于 DSH（DeepSeek Harness）的主动陪伴插件。它不是冷冰冰的定时播报器，也不是天天盯着你的查岗脚本，而是先结合日常上下文判断「现在值不值得说一句」，再带着人设与当下的心情底色自然开口：**既能接住你的消息、记住近况与日程，也有自己的好奇和念想、会主动分享发现，甚至在毫无正事时像朋友一样随口发一句「在吗」。** 你还可以 **直接在 QQ 里给她派活、让她在电脑工作台干活**——配合 `dsh-plugin-qq-bridge` 接入工作区会话外，也能在 QQ 直接吩咐她查公开资料、推进研究、整理探索笔记或跑测试，她会在 QQ 先用人设「接单」，后台做完再主动把结果带回给你。

> **测试版本说明**：本项目目前处于早期测试阶段，不同系统版本、桌面环境与手机 ROM 下的适配性尚有局限，使用中如遇到问题或异常，欢迎提交 Issue 反馈。

## 核心功能

1. **有念想、有分寸的 17 类主动由头（不只是日常关怀）**
   - **随口说一句（「在吗」与记忆种子）**：没有任何硬性事件时也不会只懂得干等。开启「随口说话（`chitchat`）」与 `judge` 后，会在避开静默期及睡眠推算时段的前提下，作为最低优先级候选上场——从近期记忆里轻挑一个种子搭话，或**每天允许发一次不带任何正事的裸招呼（如「在吗」「睡了吗」）**，由模型决定要不要发，绝不套模板硬凑。
   - **有自己的好奇与分享欲（`share` / `projectCheckIn` / `catchup`）**：后台自主探索到有意思且可核对的内容后（或私下记在 `self.md` 里的判断），会像刷到好东西一样主动发给你看；遇到需要登录才能读的页面或需要换搜索源时也会开口征询你；好几天没说话（`catchup`）或挂念你最近在忙的项目（`projectCheckIn`）时也能自然开场。
   - **真能接话、不糊弄（`reply` / `forward` / `noReply`）**：你在发送通道说话没回时会主动接住；发来链接或短视频时可先真正下载观看画面或转写口播，再结合具体内容接话，不会对着标题装懂；自己主动发消息很久没得到回应时，也会避开忙时谨慎追问一句。
   - **节制不查岗的日常照应**：兼顾课表（明早早八催睡 / 即将上课）、考试复习与临考提醒、深夜未睡 / 久坐 / 离开很久刚回来，以及手机传来的睡眠、压力与步数关心；同时内部会刻意限制「老提电脑和屏幕」的频率，连续提过就不抢其它话题。

2. **带着心情底色说话，并守住克制与边界**
   - **心情只作语气底色，不当单独由头**：整合自主探索时的临时感受（2 小时内有效）与 `emotion-state-portrait` 情绪画像，让同一句话自然带上当时的情绪温度；同时代码硬约束**不得因为心情波动就凭空找人说话**，也会剥离术语、拦截直白念出心情原文的表达。
   - **二次拿捏（`judge`）与冷落退避（`feedback`）**：触发规则后还可再过一遍大模型处境判断，免得把一句「嗯」当成必须追问的邀约；某类话题常被冷落不接时，反馈闭环会自动将其压几天、拉长间隔；全程受静默时段、忙碌时段（自动识别法定节假日与调休）、每日上限与连发退避约束。
   - **内容安全网（`guard`）与拆段说话**：发前过滤字数、客服腔、说教腔、括号动作与复读，把一句完整的话拆成几条像真人打字一样的短消息依次发出；本机口头禅与避讳写入不入库的 `local-style.json`。

3. **多通道感知、长期记忆与续聊**
   - 读取 QQ 私信、抖音私信与主对话状态，支持跨通道防重答（在抖音回过的话不会在 QQ 重复回应）。
   - 支持 QQ 连发消息合并等待、热聊顺嘴补一句、绑定会话到达上下文阈值时同工作区预建续聊，以及 QQ 主动指令与确认换源；设置页可直接挑选 `dsh-fish-memory` 历史会话并入工作区。

4. **自主探索与 DeepSeek 谷时自动调度**
   - 支持自由研究与休闲探索交替推进；可在设置页临时指定「近一轮探索主题」（跑完非跳过轮次后自动清空）。
   - 支持**只在谷时自动探索**：结合北京时间与日历缓存，按 DeepSeek API 官方低谷时段（工作日排除法定节假日后的 09:00–12:00、14:00–18:00 为高峰跳过，其余时段、周中法定节假日全天及含调休上班在内的周末全天均为谷时）自动运行。
   - 内置 2026 年法定节假日及调休安排，也可配置第三方日历 JSON 接口缓存至 `data/holidays-<年>.json`。

5. **配套手机健康感知（FishCondition / 鱼鱼状态）**
   - 安卓端采集运动健康中的起床时间、睡眠时长、步数、心率、血氧与压力范围，通过加密邮箱定时发送至电脑端，由插件用 IMAP 拉取并解析为关怀由头。

## 需要与可借用的插件

`dsh-drop-by` 本身可单独加载运行，但各感知与输出通道按需依赖以下配套插件或工具；未安装对应插件时会自动降级跳过，不会报错崩溃：

| 类别 | 插件 / 组件名称 | 作用 | 是否必需 |
|---|---|---|---|
| QQ 通道 | `dsh-plugin-qq-bridge` | 读取 QQ 私信、发送主动消息、支持热聊补句、连发合并与指令回传（需完成配对） | **QQ 场景必需** |
| 抖音感知 | `dsh-douyin-scroll` | 需开启「聊天盯梢」，用于判断抖音侧是否已聊过/已回过（插件自身不代发抖音私信） | 可选 |
| 人格注入 | `dsh-agent-md` | 提供全局 `<DSH_HOME>/AGENT.md` 与项目人格；未安装时改读本插件 `persona.md` | 推荐 |
| 长期记忆 | `dsh-fish-memory` | 读取历史记忆（支持会话文件 `session-*.json` 与工作区 `ws_*.json`），设置页可挑选会话并入工作区 | 推荐 |
| 情绪延续 | `emotion-state-portrait` | 让主动对话延续近期 QQ 聊天与自主探索的情绪基调（设置页支持一键修复本机路径配置） | 可选 |
| 网页探索 | `dsh-free-search` | 自主探索网页时优先使用其 `advanced_search`；未安装时回退到宿主 `web_search` / `web_fetch` | 可选 |
| 视频画面 | `dsh-video-storyboard` | 让模型结合视觉画面理解转发或探索到的视频（需配合支持图片的模型） | 可选 |
| 视频转写 | 本机取流脚本 + `ffmpeg` + ASR 服务 | 下载短视频、抽取音轨并转写口播；不配置也可关闭「转发视频真的看」 | 可选 |
| 手机感知 | 配套安卓 App「鱼鱼状态」+ 邮箱 IMAP/SMTP | 采集手机作息、步数与压力并邮件同步给插件 | 可选 |

## 已知局限性

- **桌面感知与 OCR 仅支持 Windows**：
  - 桌面空闲时间、前台窗口标题、音频峰值与进程列表（[tools/winprobe.ps1](tools/winprobe.ps1)）以及屏幕 OCR（[tools/screen-ocr.ps1](tools/screen-ocr.ps1)，基于 `Windows.Media.Ocr`）均通过 `powershell.exe` 与 Windows API 实现。
  - **在 macOS 或 Linux 上运行**：无法截取屏幕 OCR，也无法采集桌面在线与键鼠空闲信号（相关探测会静默降级返回不可用）；仍可使用 QQ/抖音对话感知、课表、节假日、手机状态邮件与自主探索等功能。
- **游戏与窗口受限**：
  - 屏幕 OCR 不会在窗口最小化或独占全屏游戏时生效；浏览器标签读取依赖本机开启远程调试端口的 Edge（默认 `9223`）。
- **网页探索不带个人登录态**：
  - 网页探索仅走搜索工具和 `web_fetch` 公开抓取，不会接管用户浏览器的登录 Cookie，需要登录才能看的正文网页无法直接读取完整内容。
- **视频探索的视觉依赖**：
  - 仅在已安装 `dsh-video-storyboard` 且当前模型支持多模态图片输入时可看画面，否则只依据字幕、口播转写或标题信息，不会凭空编造画面细节。
- **配套安卓端「鱼鱼状态」适配限制**：
  - 仅支持 **Android 11 及以上**系统（压力详情截图依赖 Android 11 的无障碍截屏接口）。
  - 当前页面解析规则主要适配**华为运动健康**；其中详情里的「入睡时间」因目标页面为 Canvas 自绘，无法读取文字，固定显示未读到。
  - 主动定时拉起强依赖系统「后台弹出界面」「自启动」与「电池无限制」权限，受各手机厂商省电策略影响较大。

## 电脑端插件安装与使用说明

### 1. 安装

```bash
# 从 GitHub 仓库安装到指定 DSH profile
dsh plugin --profile web add github:yuyu654/dsh-drop-by
```

安装完成后重启 DSH，即可在设置页看到「陪伴（dsh-drop-by）」配置面板。

### 2. 初始化与关键设置

插件首次运行会在插件根目录生成 `config.json`（也可参考 [config.example.json](config.example.json)），建议**直接在 DSH 设置页修改**：

1. **安全试跑与收件人**：默认 `dryRun: true`（演练模式，只记录判定不真发）且 `send.requireConfirm` 默认开启（先生成草稿）。测试通顺后填写 `channels.qq.peerId`（QQ 号或 openid），再决定是否关闭演练模式。
2. **人格与本机习惯**：若已装 `dsh-agent-md`，直接沿用其全局人格；否则插件会生成一份中性的 `persona.md` 供填写。禁用口头禅、专属称呼等个人规则可写入 `local-style.json`（参考 [local-style.example.json](local-style.example.json)，该文件不入库）。
3. **课表与节假日**：在设置页直接粘贴课表/考试纯文本即可；节假日已内置 2026 年数据，可在「日常」里手动增补额外放假/调休日期，或填入日历 JSON 接口并通过模型工具刷新缓存。
4. **记忆与情绪插件**：在「记忆」卡片可勾选发消息时读取 `session-*.json` / `ws_*.json` 的范围，或通过「挑选会话并入…」将选中历史会话合并进工作区（写前自动生成 `.bak-before-merge` 备份并支持撤销）；若接入 `emotion-state-portrait`，可点设置页「一键修复本机配置」对齐本机路径。
5. **自主探索**：在「自主探索」卡片可填写「近一轮探索主题」与「最近对什么好奇」，勾选「只在谷时自动探索」，或手动点击「试跑一轮（不发送）」验证效果。

### 3. 常用命令（开发 / 排障）

```bash
node src/run.js --status     # 查看当前插件状态与上一拍判定结果
node src/run.js --once       # 立刻执行一拍判定（dryRun 时只记日志不发送）
node src/run.js --why        # 查看上一拍命中/跳过某由头的详细原因
node src/run.js --compose    # 仅测试当前上下文会生成什么文案
node src/run.js --windows    # 查看各功能当前的执行与静默时段
npm test                     # 运行测试套件
```

运行日志按天写入插件目录的 `logs/` 下（JSONL 格式）。

## 配套安卓软件「鱼鱼状态」操作说明

> 对应版本：`v0.1.2`（versionCode 13）｜ 运行要求：Android 11 及以上 ｜ APK 可在仓库 **Releases** 页面下载。

主界面底部共有两个标签页：**主页**（状态胶囊、采集配置、推送与邮箱、权限辅助）和**设置**（原文/屏幕诊断、日志与关于）。主页顶部的**三个状态胶囊灯**是所有排查的起点：绿灯表示正常；红灯带有箭头，直接点击可跳转到对应修复设置。

### 一、首次安装五步配置

按顺序完成以下 5 步，看到第一封邮件即表示配置成功：

1. **开启无障碍权限**：主页 →「系统权限辅助」→「打开无障碍设置」→ 找到「鱼鱼状态」打开开关并点「允许」。完成后**通过手机“最近任务”切回应用**（部分系统按返回键会撤回授权），确认「● 无障碍: 已开」变绿。
2. **放行后台与保活**：主页 →「系统权限辅助」→「打开应用系统设置」，依次允许「后台弹出界面」（主动拉起必需）、开启「自启动」、将「电池」设为「不限制」；切回主页点「重新挂起前台保活」，确认「● 服务: 运行中」「● 保活: 运行中」全绿。
3. **配置邮箱发信**：主页 →「数据推送与详情」→「邮箱发送配置」，依次填写发件邮箱（如 `123456@qq.com`）、**16 位邮箱 IMAP/SMTP 授权码**（非登录密码，可在 QQ 邮箱网页版 → 设置 → 账户中开启生成）以及收件邮箱（留空则默认发给自己），点击保存。*注：不填邮箱也能本地采集，但不会对外发信。*
4. **选择界面抓取方式**（主页 →「采集与目标配置」→「界面抓取方式」）：
   - **被动采集（默认，推荐）**：你平时打开「华为运动健康」时顺手读取当前屏幕，不自动跳页面、不抢手机操作。
   - **主动拉起**：手机停留在桌面达到设定秒数且到采集间隔后，自动打开「华为运动健康」翻页取数并返回桌面。
   - **关闭**：停止自动与每日定时采集，仅保留手动按钮。
5. **手动跑通一次**：主页 →「辅助工具与测试」→「立即主动拉起一次」，等待其自动打开、采集并返回桌面；弹窗提示成功且收到第一封状态邮件即完成部署。

### 二、日常使用方式

- **场景 A｜被动采集（推荐）**：打开「华为运动健康」，在首页停留约 1 秒记录起床/睡眠/步数/心率/血氧；若需连带睡眠或压力范围，再点进「睡眠详情」（停 1～2 秒）及「情绪健康 → 压力」tab（页面为自绘图形，需停留 2～3 秒等待识别）。详情读齐后当场发信；若退出时漏了一个详情，90 秒内重新进入补看仍可合并进同一封。同一天详情默认只自动采集一次。
- **场景 B｜主动拉起**：在「停留秒数」（默认 5 秒）与「最短采集间隔」（主动默认 180 分钟、被动默认 10 分钟）设定好频率后，将手机停留在桌面即可自动执行。执行期间请勿触碰屏幕，否则会中断本轮操作。
- **场景 C｜按需采集与定时**：
  - 在「睡眠与压力详情」可单独勾选仅采集睡眠或仅采集压力；若只想就地采一次当前详情页，停在目标详情页上点击「立即采一次详情」即可就地读取（压力页就地截一张，不拉起、不跳转、不回桌面）。
  - 若需当天重采详情，点击「重置今日标记」。
  - 在「每日自动采集」填入 `HH:MM`（如 `07:30`）可设每日定时，到点后会在你**亮屏并解锁手机**后安全执行，不硬闯锁屏。

### 三、常见故障排查

排障首选看主页三个胶囊灯，或点击运行状态右上角 **「查看流水 ›」** 查看最近 8 条运行记录：

| 现象 | 常见原因与处理 |
|---|---|
| 一直收不到邮件 | 检查顶部无障碍胶囊是否为红灯（关闭无障碍开关再重新打开）；检查流水末尾是否报邮箱认证失败（重新核对 16 位授权码）。 |
| 主动拉起毫无反应 | 前往系统应用设置确认已开启「后台弹出界面」「自启动」和「电池不限制」，并在最近任务卡片中为「鱼鱼状态」加锁。 |
| 压力范围报「未认到」/ 截图失败 | 若刚覆盖安装过新版，须进系统无障碍设置把「鱼鱼状态」**关掉再重开一次**；进入压力页时停留满 2～3 秒。 |
| 压力详情被跳过 7 天 | 上一轮未识别到压力范围时会保护性跳过；点「重置今日标记」即可立刻解除。 |
| 起床时间为空 / 入睡时间总显示未读到 | 手环同步到手机有延迟时会自动等约 12 秒，首页本身无数据则为空；「入睡时间」因目标页面为 Canvas 自绘，属正常无法读取现象。 |
| 一次收到两封邮件 | 分两次进入运动健康查看详情导致拆分成两轮，一次进完所需页面即可合并；或检查是否只勾选了一项详情。 |

### 四、截图隐私边界与升级说明

- **仅两处会触发截图**：一是你或主动模式停留在「压力详情」纯图形页且开启压力采集时（仅在内存中识别出压力区间后立即丢弃，**不落盘**）；二是你在设置页亲手点击「5 秒后截图并保存至相册」（保存至 `Pictures/FishCondition/` 用于排查）。首页、睡眠页等有正常文字的界面永远不会触发截图。
- **覆盖升级必做**：安装新版 APK 会保留全部本地配置，但每次覆盖安装后**必须在系统无障碍里关闭「鱼鱼状态」再重新开启一次**，否则压力页截图会持续失败。
- **卸载与换机**：卸载会连同应用私有目录里的配置、原文与日志一并清除；更换手机需重新走一遍首次配置五步。

## 隐私与安全边界

- **本地文件与凭据不入库**：`config.json`、`credentials.json`、`state.json`、`persona.md`、`local-style.json`、`data/` 与 `logs/` 均已在 `.gitignore` 中隔离。
- **不自动点赞/刷量**：不执行任何平台关注、点赞或刷量行为，仅按配置读写私信。
- **随时总停**：可将 `enabled` 设为 `false` 或保持 `dryRun: true`。
